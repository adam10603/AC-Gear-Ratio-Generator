# AC-Gear-Ratio-Generator

![Version](https://img.shields.io/badge/Version-1.1.1-blue.svg)

## 🖊️ Description

This is a web-based tool for generating the gearbox configuration files for Assetto Corsa mod cars.

It will generate the gear ratios for the gearbox, as well as the data for the sliders on the setup screen.

Be sure to read the tooltips to get an idea for what each setting does!

The algorithm for determining the gear ratios is identical to [this calculator](https://www.desmos.com/calculator/d949b3fc08) I've made in Desmos. In addition to that version, this tool will round every gear to the closest realistic ratio (the ratio between whole numbers of gear teeth), come up with sensible adjustment ranges for each gear, then output everything in the appropriate formats that Assetto Corsa requires for car data.
